# Hiring Hub 💼

A comprehensive recruitment and career development platform built with React that connects job seekers with employers, provides career guidance, and offers motivational resources for professional growth.

## Overview

Hiring Hub is a full-stack web application designed to streamline the hiring process and support career development. It features separate dashboards for recruiters and job seekers, job listings, career tips, employer profiles, and motivational content to help professionals succeed in their careers.

## Tech Stack

**Frontend:**
- React.js
- React Router DOM (for navigation and routing)
- Font Awesome CSS (for icons)
- HTML5
- CSS3

**Backend:**
- Node.js (via server.js)
- Express.js

**State Management:**
- React Hooks (useState, useEffect)
- localStorage (for user session persistence)
